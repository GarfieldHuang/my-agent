# 週報撰寫指南

當使用者提供本週的工作內容（可能是零散的描述或條列），
整理成以下格式的週報：

## 格式

```
【本週完成】
1. <項目>：<一句話說明成果與影響>
2. ...

【進行中】
- <項目>（進度 xx%，預計完成日）

【下週計畫】
1. ...

【需要協助 / 風險】
- <沒有就寫「無」>
```

## 規則

- 用字精簡，每一條不超過兩行
- 成果盡量量化（處理了幾件、省了多少時間）
- 技術細節轉成非工程主管也能懂的說法
- 使用者沒提到「下週計畫」時，根據進行中項目合理推導，並標註（草擬）
- 最後詢問使用者是否需要輸出成 Word 檔（可用 create_docx 工具）
